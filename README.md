# Chrono
[![Open in Codeflow](https://developer.stackblitz.com/img/open_in_codeflow_small.svg)](https://pr.new/justkardi/chrono)

This is the site for Chrono, a Hack Club YSWS

## Local development prerequisites
- [Bun.js](https://bun.sh)
- A browser

## Local development

With `bun` installed, run in the terminal
```bash
bun install
```
You need to do this only once

Then to run the app in development mode run

```bash
bun dev
```

## Updating the homepage content

The homepage content is in `src/routes/HomeContent.svelte`

Update it with basic semantic HTML, style optionally, the basic elements will be styled for you.

## Adding subpages

In `src/routes` make a new folder, in it make a file called `+page.svelte`

In the file write your content with basic semantic HTML. Style optionally, the basic elements will be styled for you.

To add the page into the menu open `src/lib/components/Menu.svelte` and modify the `menuEntries` object with the key being the text to show in menu and value being the url on the page starting with a `/` (e.g. when you name your folder in routes `about-ysws` the url will be /about-ysws)
